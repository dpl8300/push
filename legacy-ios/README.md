# Legacy SwiftUI implementation

This folder contains the pre-migration SwiftUI/Xcode prototype. It is retained
only as a behavior and visual reference while the Expo implementation is
validated. The active application now lives at the repository root.

The prototype uses the bundled Orbitron Black font under the SIL Open Font
License 1.1. The license text is stored at `../../assets/fonts/Orbitron-OFL.txt`.
